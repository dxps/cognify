This project was created using `bun init` in [Bun v1.3.1](https://bun.com), using React/Shadcn+TailwindCSS template.

<br/>

### Setup

Being a Bun based project, you need to have [Bun](https://bun.sh/) installed.

-   Run `bun install` to install the project dependencies.

<br/>

### Usage

-   Run `bun dev` to start a development server.
-   Run `bun start` to run for production.
-   Run `bun build` to build for production.
